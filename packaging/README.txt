ZM-Container — 造梦西游 4 / 5 桌面客户端

Windows：解压整个压缩包，双击 zm-container.exe。
macOS：打开 DMG，将 ZM-Container.app 拖到 Applications 后启动。
macOS 仅支持 Apple 芯片（arm64）。

游戏资源启动时从官方地址获取，安装包不包含游戏资源。
账号密码在勾选“记住密码”后以明文保存在本机，请勿公开 credentials.toml。
Windows 配置目录：%APPDATA%\zm\
macOS 配置目录：~/Library/Application Support/zm/

无发行证书的 Windows 构建可能出现 SmartScreen 提示。
macOS 测试构建使用临时签名，未经过 Apple 公证，可能被 Gatekeeper 阻止。
SHA256 仅用于核对下载完整性，不等同于开发者签名。

项目与反馈：https://github.com/gcd-fj/ZM-Container
构建、签名和运行说明：仓库 docs/PACKAGING.md
